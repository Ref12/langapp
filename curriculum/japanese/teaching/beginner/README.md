# Japanese beginner route

Twelve ordered modules introduce levels 1–4, three per level. The editable
ID-only plan is `authoring/teaching/beginner.yaml`; the shared generator resolves
the compact and expanded views from the same canonical senses and constructions.
Every first-four-level introduction appears exactly once. Reviews refer only to
earlier introductions.

1. **First contact:** introductions, a drink or meal, and polite repair.
2. **Nearby people and things:** existence, belongings, and adjective contrasts.
3. **Routines and purchases:** time, past actions, quantities, yen, and preferences.
4. **Requests and plans:** destinations, te-forms, permission, and changed plans.

Start each module with a situation, then select 5–8 new senses and about one
construction for a short lesson. A module contains at most 25 new senses; it is
not a single sitting or a mastery threshold. Mix a few earlier fragile items
into later tasks and retrieve them after a delay.

The final module explicitly co-teaches plain negatives under `ja-n4-g001`
**before** the negative request `ja-n5-g030`. Te-form formation under
`ja-n5-g041` precedes te-form requests and aspect. The reference band is not a
prerequisite or teaching order.

Kana preparation can run alongside these exchanges. Initially, permit pointing,
readable support, and an appropriate audio model; never infer spoken ability
from a typed answer. Use each level's fresh-material checkpoint and the
[modality-specific rubric](../mastery.yaml), not completed-module counts.

This original AI-authored progression remains pending qualified human review.
It is not an official JLPT beginner specification or an examination guarantee.
