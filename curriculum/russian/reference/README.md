# Independent Russian reference inventory

These normalized, sense-addressed vocabulary and original grammar records
support the practical teaching program. This directory is not an official
reference band or a CEFR/TORFL level.

`vocabulary.yaml` provides Cyrillic forms, source-backed lexical readings,
selected English hints and the nine standard reference fields.
Expanded source senses and lexical identities are separately retained in
`../build/lexical-records.yaml`, not inline reference extensions.
`grammar.yaml` provides
original construction functions, explanations and bilingual examples.
Teaching order is separately authored; the position of a record in this
reference inventory does not assign learner competence.

`../build/linked-forms.yaml` links a small number of source-attested pronoun spellings
and readings to their parent lexical identities. Case interpretations beyond
the source's sparse English label are explicitly identified as original
grammatical linkage. These forms are not extra lexical headwords.
Other inflections remain in each selected source record and are addressed
by deterministic source-column form IDs when needed, rather than duplicated
as a large learner vocabulary list.

Compact learner-facing records, complete introductions/reviews, actual
coverage counts and level goals live under `../teaching/`. Keep
`../sources.yaml`, the relevant license notices and adaptation information
with any redistributed source-derived material.
